Solicitações do chat neste projeto:

1. inicie o git nesse projeto e clone o projeto "https://github.com/paulopetrillo/AKCIT_abaixo_assinado_praca_QI_11.git"

2. Neste projeto crie os seguintes arquivos com a estrutura padrão mais comum:
   - index.html
   - assets/css/style.css
   - assets/js/main.js
   (conteúdo completo fornecido pelo usuário para cada arquivo)

3. Crie uma pasta chamada "Images" dentro da pasta "assets".

4. Na classe div class="grid" aria-live="polite", crie uma tag para cada imagem dentro de assets/images da mesma forma que foi feito, conforme abaixo:
   <figure>
     <button class="thumb-btn" data-index="1" aria-label="Abrir Imagem 1">
       <img src="assets/images/Imagem01.jpg" alt="Imagem 1 - Praça" loading="lazy" />
     </button>
     <figcaption>Imagem01</figcaption>
   </figure>

5. Crie um arquivo neste projeto contendo todas as requisições deste chat.
